Cyber CTF · apt repository

Install the Cyber CTF desktop launcher on Debian/Ubuntu (amd64):

sudo curl -fsSL https://cyber-courses.github.io/apt/cyberctf-apt.asc -o /usr/share/keyrings/cyberctf.asc
echo "deb [signed-by=/usr/share/keyrings/cyberctf.asc] https://cyber-courses.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/cyberctf.list
sudo apt update
sudo apt install cyber-ctf
